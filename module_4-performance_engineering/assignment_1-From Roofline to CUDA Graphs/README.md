A hands-on assignment on measuring and optimizing GPU inference. First you build kernels across a range of arithmetic intensities, time them with CUDA events, and plot them on the roofline for your card to see what's memory-bound vs compute-bound. Next you profile a slow greedy-decode loop (no KV cache, fp32 eager, a host sync every step) and rewrite it into a fast, numerically identical version using a KV cache, fewer syncs, torch.compile, and bf16. Last you measure per-kernel launch overhead and cut it two ways: compiling a decode step into a single graph with no graph breaks, and capturing then replaying it as a hand-built CUDA graph.
